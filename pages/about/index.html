About this initiative

This project is an IT team initiative and a learning project for Senior High School interns from Rizal High.

Our purpose

Create a shared reference for collaboration between IT and other departments, project scoping, onboarding, and operating procedures.

How we contribute

Interns help organize content and build the site using HTML, CSS, and JavaScript. IT process owners review procedures and approve content before it becomes an operational reference.

This initial version contains draft examples. Assigned owners and approved procedures will be added after review.
