02 / Step reference

Process steps

This is a concise template overview; consult the source details below for reported notes and verification items.

Step Diagram reference Action or decision Responsible role / department Output or record
01 Develop Branch from dev, implement the fix, and open a pull request back to dev. IT developer (reported) Merged change in dev
02 Stage Deploy staging and return issues to the fix branch for correction. IT and QA (reported) Staging test result
03 Select and promote Copy selected staging-tested lines into pre-release and propose them for preprod. IT (reported) Preprod deployment
04 Accept and release After ASD acceptance, propose a pull request to main; approval and merge roles need confirmation. ASD and approver roles (reported) Production deployment and live checks
