# Structure

Each sidebar destination has its own `index.html` page folder. The folders follow the groups and nesting in the [table of contents](table_of_content.md). When a page summarizes a Markdown source, keep its HTML content synchronized with that source.

```text
pages/
|-- documentation/
|   |-- index.html
|   |-- rules/index.html
|   |-- conventions/index.html
|   `-- redirections/index.html
|-- glossary/
|   |-- index.html
|   |-- requests-and-ownership/index.html
|   |-- development-and-validation/index.html
|   `-- information-and-documentation/index.html
|-- structure/
|   `-- index.html
|-- implementation-workflow/
|   |-- workflow/index.html
|   |-- delivery-steps/index.html

|-- version-control-practice/

|   `-- details-to-verify/index.html
|-- list-of-teams/
|   |-- assessment-center-team/index.html

```

The unlinked legacy folders `development-validation/`, `information-documentation/`, and `requests-ownership/` are retained separately because their pages differ from the active sidebar pages. Sidebar and home-page links use the grouped folders above.
