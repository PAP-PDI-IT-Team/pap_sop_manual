# Contributor onboarding

Status: Draft — mentor review required.

## Before starting

- [ ] Meet the assigned IT mentor and confirm the internship's learning goals.
- [ ] Read README.md, CODE_OF_CONDUCT.md, SECURITY.md, and SOP.md.
- [ ] Confirm which tools, repository access, and communication channels are approved.
- [ ] Use only the access granted for your assigned work; request access through the organization's existing process.

## First contribution

- [ ] Open `index.html` and visit each starter page.
- [ ] Read STRUCTURE_SAMPLE.md and identify shared versus page-specific assets.
- [ ] Agree on a small issue with a clear scope and acceptance criteria.
- [ ] Create a branch and make the change using sanitized content.
- [ ] Check links, layout, keyboard navigation, and browser console errors.
- [ ] Submit a pull request and address mentor feedback.

## Handover

- [ ] Record completed work, remaining tasks, and supporting documentation.
- [ ] Ask the mentor to review and accept the handover.
- [ ] Follow the organization's access removal or reassignment process when the assignment ends.
